# logger (host)

Роль `host` библиотеки кодового логирования для STM32: код для ПК или сервера, который разбирает дамп энергонезависимой памяти, записанный контроллером с ролью `device_master`, обратно в массив записей с уже подставленными приоритетом и описанием. Не содержит HAL и не собирается под STM32.

## Возможности

- Разбор дампа в массив записей (`LOGDEC_Decode()`): код, источник, значение, SysTick, RTC, **`node_id`** (0 - запись самого master, 1..255 - запись пришла от slave), приоритет и описание из таблицы кодов.
- Точечный поиск описания и приоритета по коду (`LOGDEC_GetDescription()`, `LOGDEC_GetPriority()`), имя группы (`LOGDEC_GetGroupName()`).
- Форматирование записи в читаемую строку (`LOGDEC_FormatLine()`) в том же формате, что вывод master (колонка узла включена).
- Постфактум-статистика частоты вызовов по разобранному дампу (`LOGDEC_ComputeCodeStats()`, `LOGDEC_ComputeMarkStats()`).

## Требования к настройке в CubeMX

Не требуется: роль работает на ПК/сервере и не использует периферию STM32.

## Быстрый старт

Скопируйте в проект ПК-утилиты файлы папки `host`: `log_decoder.h`, `log_decoder.c`, `logger_types.h`, `logger_codes.h`. Таблица `logger_codes.h` должна быть **того же проекта**, что писал дамп (включены те же `LOGGER_ENABLE_*`), иначе описания и приоритеты не совпадут. Формат записи в дампе - 20 байт (`LOGGER_Record_t`, порядок байт хоста должен совпадать с МК, обычно little-endian).

```c
#include "log_decoder.h"

/* data/data_length - дамп, прочитанный из энергонезависимой памяти. */
LOGDEC_DecodedRecord_t records[1024];
size_t count = 0;

if (LOGDEC_Decode(data, data_length, records, 1024, &count))
{
    for (size_t i = 0; i < count; i++)
    {
        /* records[i].code/source_id/value/systick/rtc_time/node_id/priority/description */
    }
}
else
{
    /* дамп повреждён (длина не кратна размеру записи) либо records мал для всех записей */
}

/* Точечный поиск описания по коду, например для легенды в UI: */
const char *description = LOGDEC_GetDescription(0x0101U);
```

## Интеграция зависимых библиотек

Хосту нужна та же таблица кодов, что и master: новые группы зависимых библиотек добавляются блоком `#ifdef LOGGER_ENABLE_<ИМЯ>` в `logger_codes.h` (файл идентичен во всех ролях). Имя группы берётся функцией `LOGDEC_GetGroupName()` из `LOGGER_GroupNames`.

## Честные ограничения

- Дамп прежних версий библиотеки (запись 16 байт, до v2.0) этим декодером не разбирается: размер записи теперь 20 байт.
- Статистика частоты считается по всем записям кода вместе, независимо от `node_id`; для отдельных slave отфильтруйте записи по `node_id` до вызова.
- Читать файлы декодер сам не умеет: дамп передаёт вызывающий код.
- Порядок байт: запись копируется как есть, преобразования endianness нет.
